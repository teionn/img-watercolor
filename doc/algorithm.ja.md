# アルゴリズム解説：フローマップに沿ったストロークベースの絵画調レンダリング

> 中文版: [algorithm.zh.md](algorithm.zh.md)

写真を油彩のラフスケッチ風に変換するアルゴリズム。**Stroke-Based Rendering (SBR)**
の系譜に属する（多重サイズのストロークは Hertzmann 1998、方向場の平滑化は
Kang らの Edge Tangent Flow が古典）。設計の出発点は、画家が実際に絵を描くときの
手順をそのまま処理に落とし込むことにある：

- **面の方向に筆を流す**——ストロークの向きは点ごとの勾配ではなく、
  全体を平滑化した方向場から取る；
- **暗い色から明るい色へ**——全ストロークを明度順に描画し、
  実際の厚塗りと同じ重なり方をつくる；
- **描き込み密度でブラシを持ち替える**——輪郭や狭い場所は小さなハードブラシ、
  広く平坦な場所は大きなソフトブラシ；
- **情報を意図的に削ぎ落とす**——低解像度化と減色は性能上の妥協ではなく、
  画家が目を細めて対象を見るのと同じ「単純化」の工程。

## 一、パイプライン全体像

```
入力画像
 ├─ 単純化      長辺 pixels px に縮小 → バイラテラルフィルタ → k-means で palette 色に減色
 │              ├─► 減色画像（ストロークの色の取得元）
 │              ├─► ポスタライズ境界線
 │              └─► パレット可視化（スウォッチ / カラーホイール上の散布図：
 │                   色相→角度、彩度→半径、点の面積∝画素数の割合）
 ├─ 方向場      グレースケール + ガウスぼかし(normal_blur) → Sobel 勾配
 │              ├─► 法線マップ（輝度をハイトマップと見なすため青紫寄りになる）
 │              └─► 構造テンソルによる平滑化 → フローマップ θ(x,y)（エッジの接線方向）
 ├─ 密度マップ  正規化( ぼかした勾配強度 + ぼかしたポスタライズ境界線 )
 │              └─► パーセンタイルで3段階に分類：上位15% ハード / 55〜85% スタンダード /
 │                  残り ソフト。密度が高いほどブラシ径は小さく
 └─ 描画        下塗り → メイン → 描き込み の3パス。
                全ストロークを明度の暗い順に重ね、
                低解像度キャンバスからバイキュービック補間で出力サイズへ拡大
```

## 二、各ステージの詳細

### 単純化と減色（palette.py）

- 長辺を `pixels` px まで縮小する。意図的に小さく取ることで、
  形も色もこの段階で大づかみに整理される。
- k-means の前にバイラテラルフィルタを掛ける。掛けないと毛並みやテクスチャ由来の
  ごま塩状ノイズで色面の境界が崩れる。クラスタリング後のラベルにも 3×3 の
  多数決フィルタを掛けて残った斑点を除去する。
- 隣接画素でラベルが異なる箇所がポスタライズ境界線になる。可視化に使うだけでなく
  密度マップにも寄与し、さらに「トレース中に色が急変したら打ち切る」という形で
  ストロークの形状を暗黙的に拘束する。

### 法線マップとフローマップ（flowmap.py）

- ストロークの向き = エッジの接線方向（等輝度線に沿う向き）。これは
  **π 周期の「向き（orientation）」であってベクトルではない**。
  そのため平滑化とリサンプリングは構造テンソル（2θ の複素領域に相当）上で行う。
  角度をそのまま平均すると 0/π の境目で破綻する——フローマップが滑らかに
  仕上がるかどうかはここで決まる。
- 構造テンソルからはコヒーレンス（異方性の度合い）も得られる。平坦部ではほぼ 0。
- 法線マップはぼかした輝度をハイトマップと見なし、Sobel 勾配を正規化して
  RGB にエンコードしたもの。

### 密度マップとブラシの使い分け（density.py）

- 密度 = 正規化( ぼかした勾配強度 + ぼかしたポスタライズ境界線 )。
  外れ値に引きずられないようパーセンタイルで正規化する。
- ブラシ種別のしきい値もパーセンタイルで適応的に決める（ハード = 上位 15%）。
  固定しきい値だと毛並みのような高周波画像で全面ハードブラシになってしまう。
- 密度 → ブラシ半径の対応は「高いほど小さい」。ガンマ < 1 にして中程度の密度でも
  小さめのブラシに寄せ、輪郭を締める。

### ストローク描画（strokes.py + brushes.py）

- **トレース**：ジッタ付きグリッドでシード点を散布し、フローマップに沿って
  両方向へポリラインを伸ばす。各ステップで向きを直前の進行方向と同じ側に
  揃え（π 周期のため）、参照色が急変するか画面外に出たら打ち切る。
- **描画**：1 ストローク = ポリラインに沿って一定間隔でブラシテクスチャ
  （進行方向に合わせて回転したグレースケール alpha）をスタンプしていく。
  両端は**入り抜き**として不透明度を落とす（ハードブラシは弱め、ソフトは強め）。
- **描画順**：全ストロークを明度の昇順（暗→明）でソートして描く。
  明るい色が常に暗い色の上に載り、実際の厚塗りと同じ重なり方になる。
  油彩らしさの最大の源泉のひとつ。
- **ウェットブレンディング**：筆を置く直前にキャンバス上の既存色と
  `wet` の比率で混ぜる。ストローク同士が互いに色を引きずり合う。
- **側面からの色**：一部のストロークは進行方向と垂直にオフセットした位置から
  色を拾ってブレンドする。隣の色面から色を「借りる」画家の癖の再現。
- **3 パス構成**：下塗り（大きなソフトブラシ・粗い間隔）→ メイン（密度に応じて
  サイズと硬さを決定）→ 描き込み（高密度領域だけに小さなハードブラシ、
  ウェットブレンディングなし——輪郭を鈍らせないため）。
- ブラシテクスチャはプロシージャル生成（triangle ペインティングナイフ /
  flat 平筆 / soft 丸筆 / oil / pastel / charcoal）。Photoshop のブラシ先端を
  書き出したグレースケール PNG の読み込みにも対応する。
- デバッグビュー `7_strokes_debug.png` は各ストロークを種別ごとに色分けして
  描画したもの（赤 = ハード、緑 = スタンダード、青 = ソフト）。
  ブラシの割り当てが妥当かどうかの確認に使う。

## 三、質感を決める 3 つの要素

1. **低解像度キャンバス + 拡大**：長辺 `resolution` px のキャンバスで描き切ってから、
   バイキュービック補間で拡大する。ストロークの輪郭がすべてアンチエイリアスされた
   滑らかなグラデーションになる——「ブラシに見えるか、四角いブロックに見えるか」を
   分ける最大の要因。高解像度キャンバスに直接描くと、テクスチャの粗がピクセル単位の
   硬いエッジとして露出してしまう。値が小さいほど抽象的になる
   （200 だとかなりラフな筆致、360 なら細部が残る）。
2. **ソフトエッジのブラシテクスチャ**：alpha はすべて滑らかな減衰で作り、
   二値マスクは使わない。ソフトブラシにはごく薄いブリスル（毛筋）テクスチャを
   乗せ、広い面を塗ったときに流れに沿った筋が残るようにする
   （純粋なガウシアンではエアブラシのようになってしまう）。
3. **ウェットブレンディング + 入り抜き**：色が互いに移り、筆の入りと抜きがある。
   これで手描きらしい呼吸感が生まれる。

## 四、パラメータ一覧

`painterly/pipeline.py` の `PARAMS_DEFAULT`。CLI / GUI も同名：

| パラメータ | 既定値 | 意味 |
|---|---|---|
| pixels | 96 | 色取得・単純化の解像度（長辺 px）。小さいほど大づかみに |
| resolution | 360 | 描画キャンバスの長辺 px。小さいほど抽象的に |
| palette | 36 | 減色数（k-means の K） |
| color_space | rgb | 量子化の色空間 rgb / lab |
| posterize_blur | 2.0 | 減色前のガウシアン σ |
| normal_blur | 8.0 | 勾配計算前のガウシアン σ |
| brush_size | 15 | 基準ブラシ半径（キャンバス px） |
| hard/standard/soft_brush | triangle/flat/soft | 3 系統のブラシテクスチャ |
| strokes_scale | 1.0 | ストローク密度の倍率 |
| hard/standard_quantile | 0.85 / 0.55 | ブラシ種別を分けるパーセンタイルしきい値 |
| wet | 0.18 | ウェットブレンディングの混合率 |
| saturation | 1.15 | 色取得時の彩度ゲイン |
| out_long | 1080 | 出力画像の長辺（拡大後） |

## 五、コードとの対応

```
painterly/
  palette.py   単純化と減色、ポスタライズ境界線、パレット可視化
  flowmap.py   法線マップ、構造テンソルによるフローマップ
  density.py   密度マップ、ブラシサイズ・種別の割り当て
  brushes.py   ブラシテクスチャ（プロシージャル + カスタム PNG）
  strokes.py   トレース、描画順ソート、ウェットブレンディング、スタンプ描画、デバッグビュー
  pipeline.py  パイプライン統括 + 中間画像の書き出し + GUI 用フック
run.py         コマンドラインエントリポイント
gui.py         PySide6 GUI
```
